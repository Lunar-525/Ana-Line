# 音画串扰演示

在 AnaLine 中打开 `AV-Crosstalk.analine`，然后按播放。会话从 00:00 开始，伴音未静音；打开会话后保持暂停，便于准备对照。

| 时间 | 测试片内容 | 观察方法 |
| --- | --- | --- |
| 00:00–00:08 | 固定灰底，900 Hz 测试音每秒开关一次 | 看灰区的亮度、彩色条带和纹理随测试音切换而变化。 |
| 00:08–00:16 | 源音频完全静音，灰底与水平细条纹每两秒交替 | 听条纹出现时增加的嗡声与切换杂声；这些声音不是源音轨里的内容。 |
| 00:16–00:24 | 图像和测试音同时切换 | 观察并听取两种影响同时发生。 |

打开 `Clean-Reference.analine` 可对照同一片源、同一制式及播放位置。两个会话唯一的链路参数区别是 `frontEnd.enabled`。也可以在 TUNER / AGC 的 `…` 校准面板切换 **Front-end overload / nonlinearity**，比较开启和关闭后的变化。

演示采用 NTSC-M，关闭天气、地形、多径、发射端损伤和接收机老化，调谐偏移为零，C/N 为 100 dB。共享输入前端的饱和功率为 0 dB、硬度为 1、AM/PM 为 30°；IF 级使用 60 dB 饱和功率，使主要失真集中在输入级。伴音从共享 IF 提取，视频伴音陷波保持开启。共同 AGC 关闭，使用默认图像恢复 AGC。

这些是用于放大现象的演示参数，不是某款电视机的标定值。参考会话仍包含同一套有限带宽调制、滤波与解调，所以并不等同于直接播放原始视频。

已通过当前 Release 渲染器抽查各段：全部保持同步。固定灰区在测试音开关时的平均 RGB 差值，演示约 0.173、参考约 0.057；静音条纹段的接收 PCM RMS，演示约 0.00486、参考约 0.000284。伴音杂声比测试音小，第二段更容易听清。

`crosstalk-source.mkv` 是原创 24 秒测试片，含无损 H.264 视频与 48 kHz 单声道 PCM。第二段 PCM 样本全部为零，不含预先混入的干扰。三个文件使用同目录相对引用；移动时请保留整个 `AV-Crosstalk` 文件夹。
