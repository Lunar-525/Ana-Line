# Radio FM

Radio 页面提供单声道 FM 收发仿真。导入最长 5 分钟的音频（自动转换为 48 kHz 单声道），或生成 3 秒 1 kHz 测试音，然后运行收发、试听或导出接收 WAV。

链路：音频低通 → 预加重 / 限幅 → 带限升采样 → 连续相位 FM → IQ 噪声 → 调谐 → IF 低通 → 相位差鉴频 → 去加重 → 音频低通 / 降采样。

默认 IQ 采样率 384 kHz，峰值频偏 75 kHz，音频带宽 15 kHz，预加重 / 去加重 50 µs。页面支持调整频偏、调谐偏移、IQ 噪声和 0 / 50 / 75 µs 加重。参数变更后重新运行，试听与导出使用最近一次接收结果。

`AnalogCore` 的 `FMTransmitter.transmit` 和 `FMReceiver.receive` 可单独使用；`FMEngine.process` 组合完整链路。设置在初始化时校验；改变设置或跳转时重建实例。发射机接受连续 PCM 块，接收机接受任意长度的连续 IQ 块，并检查采样率、样本有限性和绝对样本位置。空块不推进时钟。采样率支持 8–192 kHz 音频和 2–32 倍整数升采样，同时要求带宽与调谐满足 Nyquist 约束。

模块复用 `TelevisionFIR`、`TVSoundFilterDesign` 和 `TVComplexResampler` 的 DSP，不依赖电视制式或帧时钟。噪声使用可重复的均匀 IQ 噪声模型；IQ 为载波附近的复数基带，不包含实际 VHF 载波采样。

首版为离线收发仿真，不连接 SDR 硬件，不含立体声 MPX、RDS、AFC、静噪或多台广播混合。输出保留因果滤波延迟，默认约 72 个音频样本（1.5 ms），起始会有滤波启动瞬态；输出长度与输入一致，结束时不额外冲刷滤波尾部。调谐偏移可能产生鉴频 DC 偏置。

验证：`swift test --filter FMTests`，覆盖音调恢复与恒包络、PCM / IQ 不规则分块、可重复噪声、调谐响应、输入校验和连续性。
