# AnaLine

独立于界面与插件宿主的 Swift 胶片效果算法原型。macOS 13+，无需第三方依赖。

## macOS 对比窗口

所有参数滑块支持双击恢复该参数的初始默认值。

顶部可切换 **Film Damage / SSTV / Terrestrial**，各模式参数独立。SSTV 实现选型见 [调研记录](SSTV-research.md)。

```sh
swift run AnaLine
```

默认载入 `Assets/bliss.jpg`，后台处理后左侧显示原图、右侧显示结果。拖动虚线或图片任意位置可改变分界。
在图片上右键选择“复制”，按当前处理分辨率写入 PNG/TIFF 剪贴板，不包含对比线、文字或原图区域；SSTV 传输中复制当前已接收的部分结果。
支持右键“粘贴”和系统粘贴命令（⌘V / 编辑菜单）导入剪贴板图片，沿用当前工具及参数。搜索框内仍使用标准文字粘贴。粘贴图片走相同的 ICC、方向与预览缩放流程，临时文件在读取后清除。
GUI 包含四个资源库，共 553 个预设：Film-Luts 6、hald-clut 350、PoLUT 196、film-lab 1。
先选择资源库，再搜索名称和选择 LUT。15 个样本随 App 提供，其余首次选择时从 GitHub 下载，
校验 Git blob SHA 后存入 `~/Library/Caches/AnalogLab/LUTs`。上游变更导致校验不匹配时会报错，
不会静默替换文件。首次处理按需执行，最近 8 个 LUT 调色结果保留在内存中供效果链复用。
切换中的旧任务会取消，过期结果不会覆盖当前选择；失败时保留上次成功的预览。
底部显示实际已渲染预设的输入和输出空间，以及哪些声明是假定。
GUI 支持 LUT Mix、程序颗粒与程序漏光；旧版色调曲线、灰尘和划痕不参与此效果链。
命令行算法保持可用。
“选择图片”按钮可以切换输入，失败时保留上一次成功的预览。
GUI 为 CPU 预览将输入最长边限制为 1400 像素，窗口缩放不会重新生成随机损伤。
也可使用 `swift run AnaLine /完整路径/image.jpg` 指定图片。
使用 `sh Scripts/build-app.sh` 可构建 Release App 并复制样图、LUT 与许可证。
Film-Luts 来源与许可说明见 `Assets/FilmLuts/ATTRIBUTION.md`。
完整资源目录、色彩空间声明和许可说明见 `Assets/LUTLibrary/ATTRIBUTION.md`。

## 统一 LUT 工序

1. 使用 ImageIO 读取源图、ICC 和 EXIF 方向，Core Image 将源图颜色转换为工作 sRGB。
2. CUBE 解析尺寸、红通道最快的排列和逐通道 DOMAIN_MIN/MAX；Hald 根据边长推算 level 与 cube size。
   Hald 读取原始 8/16 位样本，支持 RGB、灰度及不透明 alpha；不会对表内数值执行 ICC 转换。
   支持最高 256³ 的源表，包括 hald-clut 的 144³ 表。
3. 按元数据执行 sRGB 解码 → 线性 RGB/XYZ 原色矩阵转换 → LUT 输入传递函数编码。
4. 按 DOMAIN 归一化并裁切到边界，三线性插值源 LUT。
5. 按声明的输出传递函数解码，转换原色，再编码为显示 sRGB。
   Adobe RGB / Display P3 宽色域 LUT 输出额外执行 SDR 色域压缩：在线性 sRGB 中保持亮度，
   沿中性灰方向压缩色度，从色域边界的 80% 开始平滑过渡，避免负通道/超白通道被独立硬裁切。
   这是 AnaLine 的输出策略，不是 PoLUT 的一部分，也不保证感知色相严格不变。
6. 将步骤 3–5 烘焙为 65³ 的组合表，用 CIColorCube 渲染并缓存半浮点调色图。
   组合表是重采样近似；在很尖锐的局部色彩变换处可能有插值误差。未启用色域压缩的 LUT 在 SDR 输出中裁切。
7. 在显示 sRGB 中按 LUT Mix 混合原图与调色图，再添加颗粒，最后在解码的线性光中叠加漏光。
   GUI 直接显示 CGImage，不经 PNG 编码；拖动事件会合并，连续显示完成的帧。

PoLUT 默认 Adobe RGB gamma 563/256 输入与输出，包含场景到显示的色调映射，不能再叠加原来的胶片曲线。
根据[官方使用说明](https://github.com/TomPoczos/PoLUT#quick-start--darktable-setup)，
提供 LUT 前置 Exposure（−3 至 +3 EV，默认 0），在线性光中乘以 2^EV，再编码到 Adobe RGB 输入 LUT。
曝光属于 LUT 分支，Mix 0% 时不影响原图，显示型 LUT 不使用此参数；缓存同时区分预设和曝光值。
PoLUT 自身某些反转片/印纸组合对比和饱和度很强，输出压缩用于解决 sRGB 越界，不会消除预设自身的风格。
当前 JPEG/PNG 已经是显示图像，解码仅提供场景光近似，不能撤销相机的色调映射或恢复 HDR 信息。
film-lab Gold 200 的 sRGB 输入/输出有明确文档；Film-Luts 和 hald-clut 的 sRGB 是明确标注的假定。
框架同时提供 Linear sRGB、Display P3 和 Rec.709 OETF 转换，但不自动猜测未知空间。
目前支持这些库使用的 3D CUBE 与 Hald PNG，不支持 1D/shaper CUBE、任意 Log、PQ/HLG 或 RAW 工作流。

## 颗粒、混合与程序漏光

右侧效果面板可滚动。参数底栏记录当前已完成预览的设置。

- LUT Mix：0–100%；0% 关闭 LUT，但仍可使用颗粒和漏光。
- Grain Amount：颗粒强度。Size：0.5–8，按短边 1000 像素归一化的尺度。
  Texture：控制颗粒半径分布宽度，越高粒径差异越明显。
  Blur：0–2，控制扫描时颗粒覆盖场的光学平滑；叠加在固定像素孔径滤波上。
- 漏光为算法生成的多椭圆光斑，使用低频噪声扰动边缘和光量，在解码后的线性 sRGB 中增加曝光。
  控制 Amount、Position X/Y（0 为左/上）、Width、Length、Rotation、Hue、Softness、Irregularity。
  Width/Length 相对于图像短边，位置相对于整张照片，Hue 为角度。
- “换颗粒”和“换漏光”分别改变各自种子。参数调节时种子固定，窗口缩放不会重生成纹理；
  相同设备与尺寸上结果可复现，浮点 GPU 噪声不承诺跨硬件逐位一致。

预览链：原图 ICC → LUT 色彩转换 → LUT Mix → Grain → Light Leak → sRGB 显示。
GPU 效果保留源图 alpha。Grain 已替换为 Metal 泊松颗粒覆盖与扫描重建，详见 [颗粒模型与限制](Grain-model.md)；当前不是实测胶片标定或完整光谱/显影化学仿真。漏光仍为创意近似。

Bliss 测试图片来源：<https://archive.org/details/theoriginalfilesofsomewindowswallpapers>，
下载地址为 `https://archive.org/download/theoriginalfilesofsomewindowswallpapers/bliss%20600dpi.jpg`。
该样图并非本项目原创或开放许可资产。

```sh
swift test
swift run analog --demo /tmp/analog-demo.png
swift run -c release analog input.jpg output.png
swift run -c release analog input.jpg output.png recipe.json
```

`AnalogCore` 输入为非预乘 alpha 的线性 sRGB `Raster`，输出保持尺寸和 alpha。
`Recipe` 所有效果强度为 0–1；全部置零会原样返回。JSON 配方目前需要包含全部字段：

```json
{"seed":42,"film":0.7,"grain":0.25,"halation":0.3,"vignette":0.25,"lightLeak":0.15,"dust":0.2,"scratches":0.15}
```

处理顺序：胶片曲线与色偏 → 高光扩散 → 暗角 → 漏光 → 颗粒 → 灰尘和划痕。
胶片是创意近似，并非实测胶片模拟；光晕使用线性高光阈值与高斯模糊。
随机种子固定时结果可复现。灰尘和划痕使用归一化坐标，颗粒目前按像素生成。
为保证预览与导出一致，应对同一完整渲染结果缩放预览；独立低分辨率渲染尚不保证一致。

命令行只负责图片读写，当前经 8-bit sRGB 解码并导出 PNG；不保留 EXIF，不支持 HDR 输出。
核心使用 Float，但最终会裁切到 0–1。CPU 实现用于验证算法，大图性能、胶片颗粒尺度、
可标定胶片模型、分块渲染与 GPU 加速仍待实现。

## Terrestrial · 地面模拟电视

选择 Terrestrial 后载入或拖入视频。使用本机 FFmpeg/ffprobe，优先查找 PATH，再检查 Homebrew/MacPorts 的常用安装目录。PAL-D/K 转换为 720 × 576 / 25 fps，NTSC-M 转换为 720 × 480 / 29.97 fps。

视频实际经过 RGB → CVBS → 负极性 AM / VSB → 复数射频信道 → 调谐与中频滤波 → 载波恢复 / AGC → 同步与色同步恢复 → RGB。采用载波附近的复数 I/Q 等效信号，不直接采样 VHF/UHF 载波。NTSC-M 在发射时插入 7.5 IRE 黑电平基座，接收后移除。

右侧可调整信号电平、参考载噪比、中频带宽、多径幅度/延迟/相位、调谐偏移、自动微调及自动/手动增益。显示同步状态、AGC 增益、载波残差和同步置信度。失锁时继续处理信号和显示自由运行的扫描画面；短时失锁保持扫描时序，信号恢复后重新捕获。

视频下方保留常驻矩形播放条，提供播放/暂停（空格键）、进度拖动、当前/总时间和静音。连续播放按顺序处理每一帧并保留滤波器、多径、振荡器和接收机状态；CPU 不足以实时处理时降低预览速度，不跳过射频输入帧。跳转重置接收机，并使用两个冻结画面预卷帧完成捕获。切换模式、载入新视频或更换制式会暂停播放。

本阶段实现**图像射频链路**；音轨仍经 FFmpeg 转为 AAC 后直接播放，并随预览速度同步，**没有经过广播伴音调制解调**。模型为 DSP 接收仿真，尚未实现天线方向图、地形传播、真实调谐器器件非线性或标准一致性认证。参数定义、标准参考与验证范围见 [Terrestrial 技术记录](Terrestrial.md)。

## SSTV · 多模式

顶部切换 SSTV。在模式菜单中选择 Robot36、Martin M1、Scottie S1 或 PD120。输入在 sRGB 中按比例适配所选模式尺寸，补黑边，透明区合成到黑色；对比左侧为适配后的输入。
Robot36 使用 Y、交替 Cr/Cb 扫描，包含 VIS=8 头部、1200 Hz 同步、1500–2300 Hz 图像频率和标准的 150 ms 行时序。

| 模式 | 尺寸 | VIS | 含 VIS 的时长 | 扫描结构 |
| --- | --- | --- | --- | --- |
| Robot36 | 320×240 | 8 | 36.91 s | Y + 交替 Cr/Cb |
| Martin M1 | 320×256 | 44 | 115.20 s | GBR 分量扫描，行首同步 |
| Scottie S1 | 320×256 | 60 | 110.53 s | GBR 分量扫描，红色前同步 |
| PD120 | 640×496 | 95 | 127.01 s | Y0、共享 Cr/Cb、Y1，一次两行 |

Scottie 使用 PySSTV 的兼容时序约定：每个色彩扫掠 136.74 ms，两侧各有 1.5 ms 间隔。
三个新增模式通过独立 PySSTV 频率夹具检查 VIS、完整时序、颜色和扫描顺序；另测流式损伤、已接收行保持及切换模式的缓存/会话失效。
生成夹具脚本为 `Scripts/generate-sstv-mode-fixtures.py`，Python 与 PySSTV 仅用于开发验证。

相邻两行共享恢复的色度，所以无损伤往返仍有色度子采样和边界采样误差。

纯 Swift 在 12 kHz 下生成以 1900 Hz 为中心的复数基带（I/Q），保持连续相位。
信道内执行损伤，再以相邻复数样本的相位差进行 FM 解调，按像素停留时间积分并重建 RGB。
快速预览计算所选模式的完整信号样本，不按播放速度等待，也不经过声卡或反复写入 WAV。
图片不变时 TX 缓存复用，仅重算信道和 RX；换图清除缓存，取消旧任务并合并滑块请求。
当前本机 Release 测试的参考耗时约 TX 3 ms、RX 7–8 ms（320×240），不包含 UI 调度，不作跨设备保证。

控制项：

- Noise：复数接收噪声幅度，0 为无噪声；近似高斯分布，不是 dB/SNR 刻度。
- Frequency Offset：恒定频偏，−400～+400 Hz；Drift：整段信号的频率变化量，以零为中心。
- Clock Error：−3000～+3000 ppm，通过重采样信号模拟接收时钟偏差。
- Dropout：每个 100 ms 信号块发生掉信号的概率，命中时其中 70 ms 静音；显示值不是总静音时长百分比。
- Interference：叠加相干窄带音的幅度，Tone 1000～2800 Hz。
- 局部同步追踪：在已知行时序附近寻找同步脉冲，默认关闭以保留倾斜；强失真下可能无法追踪。
- Seed：固定信道噪声/掉信号随机场；Mix：重建结果与适配后原图混合，0% 直接旁路。

接收端已知模式和起点，支持以上四种模式，尚不包含 VIS 自动检测、任意录音导入、完全失锁后的重捕获、
自动频偏校准或 WAV 导出。复数基带是音频调制信号的等效表示；当前接收器和信道是
可控的创意仿真，没有建模完整 RF 前端、传播、AGC 或窄带接收滤波器，不能视为完整无线电接收机。

验证包括色条往返、时长、六类损伤、随机复现、同步追踪、Mix 旁路与缓存失效。
使用 [PySSTV](https://github.com/dnet/pySSTV) 独立编码生成的频率序列验证 TX 时序/颜色与 RX；
该验证不是对任意真实 PCM 录音的互操作保证。参考数据见 `Tests/Fixtures/robot36-pysstv-bars.json`。

### 可玩的 TX/RX 过程与麦克风

SSTV 面板顶部的“传输台”提供开始、重新发送、停止与 1×/4×/16× 速度。
传输时长随模式变化，面板显示含 VIS 的总时长；速度可加速至 16×，UI 调度会带来少量误差。切换模式会停止当前传输并重新适配输入图片。
接收器逐段处理真实信号样本，图像按完整的色度行对逐渐出现，橙线标记接收位置。
运行中调整损伤只影响后续信号；已提交的行保留。Mix 可重新混合已接收区域。
停止保留当前部分结果；“快速预览完整结果”退出传输过程并即时重算整张图，不混入麦克风。

“监听 TX 声音”默认关闭，仅在 1× 时播放由复数 TX 还原的实际单声道调频音频；加速时暂停声音监听。
麦克风默认关闭，用户开启时才请求 macOS 权限，需运行 `build/AnaLine.app`。
权限用途已写入 Info.plist，构建脚本对 App 做本地 ad-hoc 签名（不是 Developer ID 公证）。

开启麦克风后显示输入电平，Mic Gain 控制混入幅度。硬件 PCM 转成 12 kHz，经 1900 Hz 正交下变频和
两级 1 kHz 低通后混入 RX 的复数信号，声音的实际波形/频率/相位会改变解调结果，而非仅通过音量生成随机噪声。
硬件 PCM 采样率转换使用带状态的两级抗混叠平滑与速率累加器；低采样率输入采用保持插值，属于实时创意近似。
1× 使用最近捕获片段；4×/16× 会循环当前短片段填充额外的仿真时间，不改变声音音调来加速。
输入电平仅作显示（线性 RMS ×4），不会自动归一化声音。静音或 Mic Gain 0 不产生麦克风损伤。

麦克风音频仅暂存在内存，不写入文件或上传。停止、传输结束、切换工具、换图或关窗时自动关闭捕获；
权限拒绝或设备不可用会显示状态。扬声器监听的 TX 音频可能被麦克风再次拾取，耳机可避免这类回授。
模拟波形测试覆盖了麦克风混入与分块一致性；真实设备权限、输入路由和声音播放仍需在具体 Mac 上验证。

### 时变信道

“波动强度”从 0–100% 控制时变环境，“波动时间”0.2–8 秒控制相关变化速度。
Noise、Frequency Offset、Drift、Clock Error 等滑块成为基准值；强度 0 保留可校准的固定条件，
“弱信号”“漂移”快捷设置默认开启波动。

基于固定种子的连续插值随机轨迹，在信号时间轴上叠加快/慢频偏游移、时钟速率漂移、噪声底起伏、
相关信号衰落、干扰幅度/频率变化及稀疏突发事件。动态噪声与干扰突发可在对应基准值为 0 时出现；
关闭波动可禁用这些额外事件。波动不是逐帧随机重抽，也不是每行独立改参数。
控制轨迹按 10 ms 信号时间更新，与 UI 帧率、处理分块和 1×/4×/16× 的播放速度无关。
传输中显示实际噪声强度、瞬时频偏、时钟 ppm 和信号幅度；原始滑块显示基准值。

时钟误差通过积分累积采样时间偏移；FM 频偏连续累积相位，所以变化不会通过重新乘绝对时间
制造不连续的采样跳跃。固定种子可复现轨迹，改种子可得到另一种环境；真实麦克风仍属于不可重放的实时输入。
这是一种可控的时变创意信道模型，不是对特定电台、传播路径或硬件的实测拟合。
