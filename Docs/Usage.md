# AnaLine

独立于界面与插件宿主的 Swift 胶片效果算法原型。macOS 13+，无需第三方依赖。

## macOS 对比窗口

所有参数滑块支持双击恢复该参数的初始默认值。

顶部可切换 **Film Damage / SSTV / Terrestrial**，各模式参数独立。SSTV 实现选型见 [调研记录](SSTV-research.md)。

```sh
swift run AnaLine
```

默认载入 `Assets/bliss.jpg`，后台处理后左侧显示原图、右侧显示结果。拖动虚线或图片任意位置可改变分界。

支持右键“粘贴”和系统粘贴命令（⌘V / 编辑菜单）导入剪贴板图片，沿用当前工具及参数。搜索框内仍使用标准文字粘贴。粘贴图片走相同的 ICC、方向与预览缩放流程，临时文件在读取后清除。
GUI 包含四个资源库，共 553 个预设：Film-Luts 6、hald-clut 350、PoLUT 196、film-lab 1。

不会静默替换文件。首次处理按需执行，最近 8 个 LUT 调色结果保留在内存中供效果链复用。
切换中的旧任务会取消，过期结果不会覆盖当前选择；失败时保留上次成功的预览。

命令行算法保持可用。

## 统一 LUT 工序

1. 使用 ImageIO 读取源图、ICC 和 EXIF 方向，Core Image 将源图颜色转换为工作 sRGB。
2. CUBE 解析尺寸、红通道最快的排列和逐通道 DOMAIN_MIN/MAX；Hald 根据边长推算 level 与 cube size。
   Hald 读取原始 8/16 位样本，支持 RGB、灰度及不透明 alpha；不会对表内数值执行 ICC 转换。
   支持最高 256³ 的源表，包括 hald-clut 的 144³ 表。
3. 按元数据执行 sRGB 解码 → 线性 RGB/XYZ 原色矩阵转换 → LUT 输入传递函数编码。
4. 按 DOMAIN 归一化并裁切到边界，三线性插值源 LUT。
5. 按声明的输出传递函数解码，转换原色，再编码为显示 sRGB。
   Adobe RGB / Display P3 宽色域 LUT 输出额外执行 SDR 色域压缩：在线性 sRGB 中保持亮度，
   沿中性灰方向压缩色度，从色域边界的 80% 开始平滑过渡，避免负通道/超白通道被独立硬裁切。
   这是 AnaLine 的输出策略，不是 PoLUT 的一部分，也不保证感知色相严格不变。
6. 将步骤 3–5 烘焙为 65³ 的组合表，用 CIColorCube 渲染并缓存半浮点调色图。
   组合表是重采样近似；在很尖锐的局部色彩变换处可能有插值误差。未启用色域压缩的 LUT 在 SDR 输出中裁切。
7. 在显示 sRGB 中按 LUT Mix 混合原图与调色图，再添加颗粒，最后在解码的线性光中叠加漏光。
   GUI 直接显示 CGImage，不经 PNG 编码；拖动事件会合并，连续显示完成的帧。

PoLUT 默认 Adobe RGB gamma 563/256 输入与输出，包含场景到显示的色调映射，不能再叠加原来的胶片曲线。
根据[官方使用说明](https://github.com/TomPoczos/PoLUT#quick-start--darktable-setup)，
提供 LUT 前置 Exposure（−3 至 +3 EV，默认 0），在线性光中乘以 2^EV，再编码到 Adobe RGB 输入 LUT。
曝光属于 LUT 分支，Mix 0% 时不影响原图，显示型 LUT 不使用此参数；缓存同时区分预设和曝光值。
PoLUT 自身某些反转片/印纸组合对比和饱和度很强，输出压缩用于解决 sRGB 越界，不会消除预设自身的风格。
当前 JPEG/PNG 已经是显示图像，解码仅提供场景光近似，不能撤销相机的色调映射或恢复 HDR 信息。
film-lab Gold 200 的 sRGB 输入/输出有明确文档；Film-Luts 和 hald-clut 的 sRGB 是明确标注的假定。
框架同时提供 Linear sRGB、Display P3 和 Rec.709 OETF 转换，但不自动猜测未知空间。
目前支持这些库使用的 3D CUBE 与 Hald PNG，不支持 1D/shaper CUBE、任意 Log、PQ/HLG 或 RAW 工作流。

## 颗粒、混合与程序漏光

右侧效果面板可滚动。参数底栏记录当前已完成预览的设置。

- LUT Mix：0–100%；0% 关闭 LUT，但仍可使用颗粒和漏光。
- Grain Amount：颗粒强度。Size：0.5–8，按短边 1000 像素归一化的尺度。
  Texture：控制颗粒半径分布宽度，越高粒径差异越明显。
  Blur：0–2，控制扫描时颗粒覆盖场的光学平滑；叠加在固定像素孔径滤波上。
- 漏光为算法生成的多椭圆光斑，使用低频噪声扰动边缘和光量，在解码后的线性 sRGB 中增加曝光。
  控制 Amount、Position X/Y（0 为左/上）、Width、Length、Rotation、Hue、Softness、Irregularity。
  Width/Length 相对于图像短边，位置相对于整张照片，Hue 为角度。
- “换颗粒”和“换漏光”分别改变各自种子。参数调节时种子固定，窗口缩放不会重生成纹理；
  相同设备与尺寸上结果可复现，浮点 GPU 噪声不承诺跨硬件逐位一致。

预览链：原图 ICC → LUT 色彩转换 → LUT Mix → Grain → Light Leak → sRGB 显示。
GPU 效果保留源图 alpha。Grain 已替换为 Metal 泊松颗粒覆盖与扫描重建，详见 [颗粒模型与限制](Grain-model.md)；当前不是实测胶片标定或完整光谱/显影化学仿真。漏光仍为创意近似。

Bliss 测试图片来源：<https://archive.org/details/theoriginalfilesofsomewindowswallpapers>，
下载地址为 `https://archive.org/download/theoriginalfilesofsomewindowswallpapers/bliss%20600dpi.jpg`。
该样图并非本项目原创或开放许可资产。

```sh
swift test
swift run analog --demo /tmp/analog-demo.png
swift run -c release analog input.jpg output.png
swift run -c release analog input.jpg output.png recipe.json
```

`AnalogCore` 输入为非预乘 alpha 的线性 sRGB `Raster`，输出保持尺寸和 alpha。
`Recipe` 所有效果强度为 0–1；全部置零会原样返回。JSON 配方目前需要包含全部字段：

```json
{"seed":42,"film":0.7,"grain":0.25,"halation":0.3,"vignette":0.25,"lightLeak":0.15,"dust":0.2,"scratches":0.15}
```

处理顺序：胶片曲线与色偏 → 高光扩散 → 暗角 → 漏光 → 颗粒 → 灰尘和划痕。
胶片是创意近似，并非实测胶片模拟；光晕使用线性高光阈值与高斯模糊。
随机种子固定时结果可复现。灰尘和划痕使用归一化坐标，颗粒目前按像素生成。
为保证预览与导出一致，应对同一完整渲染结果缩放预览；独立低分辨率渲染尚不保证一致。

命令行只负责图片读写，当前经 8-bit sRGB 解码并导出 PNG；不保留 EXIF，不支持 HDR 输出。
核心使用 Float，但最终会裁切到 0–1。CPU 实现用于验证算法，大图性能、胶片颗粒尺度、
可标定胶片模型、分块渲染与 GPU 加速仍待实现。

## Terrestrial · 地面模拟电视

接收状态区提供 **H Sync / V Sync / Color Sync** 三个独立指示灯：绿色为检测到同步，橙色为短暂同步保持，红色为搜索同步，灰色为未载入视频或正在预处理。悬停可查看状态。场同步或色同步丢失时，行同步可能仍保持锁定。

选择 Terrestrial 后，无视频的监视器以 25 Hz 持续显示灰度雪花，叠加系统安装的 VCR OSD Mono 字体提示拖入视频或点击 Choose Video；首次导入期间显示 PREPARING VIDEO / PAL + NTSC / PLEASE WAIT。雪花使用局部纹理动画，不运行完整 RF 链路、不刷新工作区；离开监视器后停止，系统减少动态效果时保留静态雪花。播放条仍在鼠标移入监视器时显示，无输入时控件不可操作；拖放入口仍可使用。

载入或拖入视频使用本机 FFmpeg/ffprobe，优先查找 PATH，再检查 Homebrew/MacPorts 的常用安装目录。首次导入解码一次并分为两个分支，从原视频分别生成 PAL-D/K 的 720 × 576 / 25 fps 和 NTSC-M 的 720 × 480 / 29.97 fps；单声道 48 kHz PCM 音频准备一次，补齐到两份视频中较长的时长。顶部下方的矩形进度条显示 FFmpeg 的实际处理进度，并区分 PAL + NTSC 视频转换和 PCM 音频准备；检查缓存或无法读取源时长时显示持续移动的活动条；FFmpeg 每 0.1 秒发布进度，界面平滑更新，不等阶段完成才跳动。缓存的关键帧间隔约一秒，减少打开对应位置时的前向解码。后续切换制式直接选择已有缓存，将播放位置对齐到最近的目标制式帧并重新捕获接收机，反复切换不会逐次向前取整产生位置漂移，不再读取原视频或重新转码。首次转换结果持久保存在设置指定的磁盘缓存中，以原视频完整 SHA-256 和转换版本为键；改名、移动相同内容也可命中，内容变化或不完整缓存会重新转换。命中时直接读取两份视频与 PCM 元数据，不再进行 FFmpeg/ffprobe 预处理。未命中或转换结果超过容量时使用临时文件；失败的替换导入保留原来的完整缓存。

Broadcast standard 使用与顶部模式开关一致的矩形按钮，黄色块标记当前制式。悬停在 PAL-D/K 或 NTSC-M 上可查看扫描制式、频道带宽和伴音参数。

视频实际经过 RGB → CVBS → 负极性 AM / VSB → 复数射频信道 → 调谐与中频滤波 → 载波恢复 / AGC → 同步与色同步恢复 → RGB。采用载波附近的复数 I/Q 等效信号，不直接采样 VHF/UHF 载波。NTSC-M 在发射时插入 7.5 IRE 黑电平基座，接收后移除。

Propagation 位于固定 4:3 监视器右侧，制式切换条下方，采用近黑色主题：灰白天线与刻度、柔金色信号路径、低饱和蓝色地面反射与紫色附加反射。天气图形与局部精确编辑浮层统一使用暗色配色。天空、地形、天线与反射路径合并成一张交互图，常驻头部只有整体旁路与重置。拖动接收天线杆调整距离和高度，拖天线振子旋转仰角，滚轮调整 −5～25 dBi 增益，右键更换偶极子、八木、对数周期或蝶形阵列；更换类型会载入该类型的默认增益。拖发射塔顶调整高度。右键场景添加山脊，拖顶点改变高度和位置，右键山顶移除。折射曲线上的风形标记可拖动／滚动调整基础 k，点击查看精确值与包含天气作用的有效 k。地球曲率、天线方向和第一菲涅尔区仍由传播模型计算；高度夸张显示。数值在悬停或拖动时显示，双击天线、塔顶、山顶或附加反射点打开精确编辑浮层。黄色信号路径的悬停提示显示自由空间、绕射、方向、天气损耗和相对链路增益；这些读数没有 dBm 标定。载频 50～860 MHz 已移入 Transmitter 正面旋钮，重置传播场景会保留载频。

“编码／发射”以三块设备面板纵向堆叠，旋钮横向排列：青色 Encoder、2U 黑金 VSB / Group Delay、3U 黑色 Transmitter；发射机散热鳍片位于机柜顶面。Encoder 与 VSB 采用紧凑面板，旋钮右侧放置数码管读数及单位。左侧银白色矩形翘板开关启用对应的老化／非线性模型，其材质与旋钮一致；BYPASS 保留参数，仍正常编码、调制和发射。上下拖动或在旋钮上滚动调整，按住 Shift 精调，双击复位，数值采用琥珀色七段数码管，点击后输入数值，按回车或移开焦点后恢复数码显示。触控板惯性不会继续改变参数。每块右上角的“…”打开检修面板，放置 burst 校准、功放陡峭度、AM/PM、载波交叉压缩与负载 VSWR 等细节。

Transmitter 正面新增发射功率旋钮（−60～+12 dB，默认 0 dB），以原有标称载波功率为参考，图像与伴音一同调节。该旋钮在 PA 压缩前改变驱动，因此提高功率可能触发饱和，实际输出不一定按设定值线性增加；PA 的 BYPASS 开关不影响发射功率旋钮。

“03 · 接收／重建”与 Encoding/TX 并排位于播放器下方，合并为 Tuner / AGC 和 Sync / Y-C 两块深色控制面板，腾出的下部空间放置 Reception 与 RX spectrum / waterfall 仪表。银白旋钮与七段读数沿用发射机的滚轮、拖动、精调和数值输入操作。调谐器左侧开关控制自动增益，关闭后 AGC 响应旋钮的位置切换为手动增益；AFT 控制自动微调，AGC LAG 单独启用迟滞与过冲。Sync 左侧开关仅旁路同步老化，Y/C 分离仍生效；COMB / NOTCH 与 PAL DELAY 直接切换。亮度敏感 AGC、行响应、同步死区、行振荡器偏差和场捕获窗口保留在“…”检修面板。顶部重置仅恢复接收设置，保留发射机、传播、天气与多径。仪表采用黑色机架、凹入式暗色屏幕、灰绿色读数、独立 H/V/Color 指示灯和琥珀色 VSB/FM 按钮。静态控制面板继续只观察配置，接收读数与瀑布图独立刷新。

发射机黄色背光表显示 PA 前向功率与负载返回功率，采用相对参考功率的百分比刻度，无瓦数标定；超过表盘刻度时数值仍显示实际读数。PA SATURATION 来自图像／伴音 PA 驱动包络达到饱和参考，OVERMODULATION 来自图像 AM 包络反转或伴音预加重后的限幅。负载 VSWR 默认 1:1，没有返回功率；增大 VSWR 会减少进入传播链路的功率。天气与接收端反射路径不作为发射端返回功率。无视频时表盘停止并显示空读数。

Propagation 天空中常驻太阳、温度计和湿度水滴。右键天空添加雨、雪、雾、雷电、电离层远台干扰与杂波，启用的元素直接显示在天空里。上下拖动图形增强／减弱，悬停显示物理单位；雷云上下拖动调单次强度（0～100%），左右拖动调平均发生频率（0～120 次/分钟，默认 30 次/分钟），方向在一次拖动开始时锁定，避免误改另一个参数。雷云悬停同时显示强度与频率，右键“编辑数值”可分别输入。频率是随机发生的平均值，并非固定间隔；强度不再影响事件的时刻或数量，只改变 RF 脉冲幅度与闪光亮度。任一项归零停止雷击，频率归零保留雷云与强度以便再次调整。云下电弧数量示意频率，亮度与粗细示意强度。双击恢复默认值，右键可精确编辑、移除元素或旁路天气并保留设置。雨滴持续下落，雨雪密度和雾层同时绘制在 TX→RX 路径上。雨滴动画独立最高 12 Hz；雷电分叉电弧使用 RF 链路的同一事件，随受干扰的解码帧呈现，同时使整个 Propagation 面板（含标题与边缘）短暂亮起冷白光，约 0.16 秒内衰减；电弧按播放时间保留约 0.32 秒余辉，不会随八帧预处理缓冲提前闪现。暂停冻结闪电，跳转／换源清除旧余辉，场景／天气旁路不产生雷击；无视频时只显示雷电强度与频率的静态图标。紧凑天气图标使用静态强度示意，关闭场景／天气或系统减少动态效果时停止雨滴运动。整体旁路同时关闭场景和附加回波，保留回波幅度及编辑值，重新启用后恢复。动画不写 RF 配置；只有闪电与面板亮光的小画布跟随相关视频帧刷新，地形与控制面板不跟随刷新。天气影响吸收、湿润表面损耗、杂波、假定折射梯度与热噪声，雷电加入 RF 脉冲，图像与 FM 伴音共同受到影响。

独立 RF Channel 和传播细节参数区已移除。右键场景添加一条附加反射路径：上下拖动菱形反射点改变等效额外路程（c × 延迟，0～20 μs），滚轮调整回波幅度，点击路径或右键反射点编辑幅度／延迟／相位，删除令幅度归零。该等效反射点的纵向比例独立于地形高度，不能解释为实测障碍物位置。点击地面调整地面反射强度，蓝色路径延迟由距离与 TX/RX 高度计算；附加回波以紫色显示，两者分别进入原有模型。信号电平与参考载噪比滑块已移除；接收电平由发射功率、传播、天线、地形和天气形成。接收端继续提供中频带宽、调谐、自动微调、AGC 与同步恢复；失锁时继续处理并显示自由运行的扫描画面。

接收机下部仪表提供真实 RX I/Q 的频谱曲线与最近 10 秒的瀑布图。VSB 查看图像调谐/中频滤波之后、AGC 之前的信号；FM 查看伴音分支通过公共射频前端带宽后的信号，位于伴音 AFC/中频与鉴频之前。两条窄带包络分别测量，可通过 VSB / FM 切换，没有合成为一个全频道 RF 采样信号。横轴为相对调谐参考的 MHz，虚线标出调谐后的标称载波位置。色标固定为 −100～0 dBFS/bin，弱信号不会被自动增亮；这不是 dBm 校准值。最新测量在顶部，每行 100 ms；没有测量的时间段留黑。暂停保留历史，跳转、更换源/制式或伴音频轴改变时清空相应历史。

矩形播放条位于视频画面内部底部，监视器没有额外的半透明黑色底框或画面外留边；鼠标移入播放器时显示、移出时隐藏，提供播放/暂停（空格键）、进度拖动、当前/总时间和静音。拖动进度时即使鼠标暂时移出画面，播放条也保持显示直到松开；隐藏后仍可用空格键播放或暂停。正常连续播放按顺序处理每帧并保留滤波器、多径、振荡器和接收机状态。播放时钟固定为 1×；缓冲不足时丢弃过期帧，并按最近处理耗时提前生成可及时显示的帧。跳过 RF 时间段后重新建立接收状态，不执行暂停预览用的额外冻结画面预卷。跳转重置接收机，并使用两个冻结画面预卷帧完成捕获。切换模式、载入新视频或更换制式会暂停播放。

顶部状态显示 RF 接收耗时、整帧处理耗时、当前播放倍率与本次播放的生成峰值。整帧包含取帧、CVBS 编码、RF/伴音与图像转换，不包含首次转码或跳转预卷，也不等同于窗口合成耗时。峰值测量完整后台生成墙钟与入队开销，不做平均，重新播放时清零。后台生成器提前处理音画（默认八帧，设置中可调 1～60 帧，下次播放生效），显示器独立跟随音频时钟；某帧生成变慢时，已缓存的画面仍继续显示。启动时需先填充这段缓冲。正常速度下生成器无需等待主线程；缓冲不足时保持正常速度，过期视频帧和迟到 PCM 丢弃，音频缺口输出静音。1.0× 显示绿色，其他速度显示红色；发生丢帧时显示红色 DROP 与本次播放累计次数，重新播放时清零。每帧图像、时间和接收指标只刷新预览、播放条与接收读数；天线、天气参数、右侧参数和工作区布局不随视频帧刷新；雨滴动画拥有独立的局部时钟，闪电仅由呈现的 RF 雷击事件驱动。

图像与播放进度维持原帧率；接收指标、同步灯和频谱按 100 ms 媒体时间桶刷新。播放期间向 macOS 声明对延迟敏感的用户活动，暂停或结束后释放。

音频会混合为 48 kHz 单声道，经过限带、预加重、FM 调制、射频信道、伴音中频、鉴频与去加重。PAL-D/K 使用 +6.5 MHz 的主伴音载波，NTSC-M 使用 +4.5 MHz；图像和伴音共用电平、载噪比、多径与调谐参数。中频收得过窄时，可能还有画面却没有伴音。当前没有 BTSC/A2/NICAM 立体声或图像引入的伴音蜂鸣模型。

声音通过原生 PCM 输出缓冲播放，画面跟随音频消费时钟；暂停或跳转会清空旧缓冲。CPU 处理跟不上时仍按 1× 消费音频时间，迟到音频不会堆积到后面播放。静音只关闭声音，不暂停播放。没有音轨的视频继续正常播放；音频设备启动失败会在顶部显示错误。传播、天线方向图与天气使用可控的简化模型，未作实测设备或气象标定；目前没有地形地图、多障碍波场求解、真实调谐器器件非线性或标准一致性认证。参数定义、系数与验证范围见 [Terrestrial 技术记录](Terrestrial.md)。

## SSTV · 多模式

顶部切换 SSTV。在模式菜单中选择 Robot36、Martin M1、Scottie S1 或 PD120。输入在 sRGB 中按比例适配所选模式尺寸，补黑边，透明区合成到黑色；对比左侧为适配后的输入。
Robot36 使用 Y、交替 Cr/Cb 扫描，包含 VIS=8 头部、1200 Hz 同步、1500–2300 Hz 图像频率和标准的 150 ms 行时序。

| 模式 | 尺寸 | VIS | 含 VIS 的时长 | 扫描结构 |
| --- | --- | --- | --- | --- |
| Robot36 | 320×240 | 8 | 36.91 s | Y + 交替 Cr/Cb |
| Martin M1 | 320×256 | 44 | 115.20 s | GBR 分量扫描，行首同步 |
| Scottie S1 | 320×256 | 60 | 110.53 s | GBR 分量扫描，红色前同步 |
| PD120 | 640×496 | 95 | 127.01 s | Y0、共享 Cr/Cb、Y1，一次两行 |

Scottie 使用 PySSTV 的兼容时序约定：每个色彩扫掠 136.74 ms，两侧各有 1.5 ms 间隔。
三个新增模式通过独立 PySSTV 频率夹具检查 VIS、完整时序、颜色和扫描顺序；另测流式损伤、已接收行保持及切换模式的缓存/会话失效。
生成夹具脚本为 `Scripts/generate-sstv-mode-fixtures.py`，Python 与 PySSTV 仅用于开发验证。

相邻两行共享恢复的色度，所以无损伤往返仍有色度子采样和边界采样误差。

纯 Swift 在 12 kHz 下生成以 1900 Hz 为中心的复数基带（I/Q），保持连续相位。
信道内执行损伤，再以相邻复数样本的相位差进行 FM 解调，按像素停留时间积分并重建 RGB。
快速预览计算所选模式的完整信号样本，不按播放速度等待，也不经过声卡或反复写入 WAV。
图片不变时 TX 缓存复用，仅重算信道和 RX；换图清除缓存，取消旧任务并合并滑块请求。
当前本机 Release 测试的参考耗时约 TX 3 ms、RX 7–8 ms（320×240），不包含 UI 调度，不作跨设备保证。

控制项：

- Noise：复数接收噪声幅度，0 为无噪声；近似高斯分布，不是 dB/SNR 刻度。
- Frequency Offset：恒定频偏，−400～+400 Hz；Drift：整段信号的频率变化量，以零为中心。
- Clock Error：−3000～+3000 ppm，通过重采样信号模拟接收时钟偏差。
- Dropout：每个 100 ms 信号块发生掉信号的概率，命中时其中 70 ms 静音；显示值不是总静音时长百分比。
- Interference：叠加相干窄带音的幅度，Tone 1000～2800 Hz。
- 局部同步追踪：在已知行时序附近寻找同步脉冲，默认关闭以保留倾斜；强失真下可能无法追踪。
- Seed：固定信道噪声/掉信号随机场；Mix：重建结果与适配后原图混合，0% 直接旁路。

接收端已知模式和起点，支持以上四种模式，尚不包含 VIS 自动检测、任意录音导入、完全失锁后的重捕获、
自动频偏校准或 WAV 导出。复数基带是音频调制信号的等效表示；当前接收器和信道是
可控的创意仿真，没有建模完整 RF 前端、传播、AGC 或窄带接收滤波器，不能视为完整无线电接收机。

验证包括色条往返、时长、六类损伤、随机复现、同步追踪、Mix 旁路与缓存失效。
使用 [PySSTV](https://github.com/dnet/pySSTV) 独立编码生成的频率序列验证 TX 时序/颜色与 RX；
该验证不是对任意真实 PCM 录音的互操作保证。参考数据见 `Tests/Fixtures/robot36-pysstv-bars.json`。

### 可玩的 TX/RX 过程与麦克风

SSTV 面板顶部的“传输台”提供开始、重新发送、停止与 1×/4×/16× 速度。
传输时长随模式变化，面板显示含 VIS 的总时长；速度可加速至 16×，UI 调度会带来少量误差。切换模式会停止当前传输并重新适配输入图片。
接收器逐段处理真实信号样本，图像按完整的色度行对逐渐出现，橙线标记接收位置。
运行中调整损伤只影响后续信号；已提交的行保留。Mix 可重新混合已接收区域。
停止保留当前部分结果；“快速预览完整结果”退出传输过程并即时重算整张图，不混入麦克风。

“监听 TX 声音”默认关闭，仅在 1× 时播放由复数 TX 还原的实际单声道调频音频；加速时暂停声音监听。
麦克风默认关闭，用户开启时才请求 macOS 权限，需运行 `build/AnaLine.app`。
权限用途已写入 Info.plist，构建脚本对 App 做本地 ad-hoc 签名（不是 Developer ID 公证）。

开启麦克风后显示输入电平，Mic Gain 控制混入幅度。硬件 PCM 转成 12 kHz，经 1900 Hz 正交下变频和
两级 1 kHz 低通后混入 RX 的复数信号，声音的实际波形/频率/相位会改变解调结果，而非仅通过音量生成随机噪声。
硬件 PCM 采样率转换使用带状态的两级抗混叠平滑与速率累加器；低采样率输入采用保持插值，属于实时创意近似。
1× 使用最近捕获片段；4×/16× 会循环当前短片段填充额外的仿真时间，不改变声音音调来加速。
输入电平仅作显示（线性 RMS ×4），不会自动归一化声音。静音或 Mic Gain 0 不产生麦克风损伤。

麦克风音频仅暂存在内存，不写入文件或上传。停止、传输结束、切换工具、换图或关窗时自动关闭捕获；
权限拒绝或设备不可用会显示状态。扬声器监听的 TX 音频可能被麦克风再次拾取，耳机可避免这类回授。
模拟波形测试覆盖了麦克风混入与分块一致性；真实设备权限、输入路由和声音播放仍需在具体 Mac 上验证。

### 时变信道

“波动强度”从 0–100% 控制时变环境，“波动时间”0.2–8 秒控制相关变化速度。
Noise、Frequency Offset、Drift、Clock Error 等滑块成为基准值；强度 0 保留可校准的固定条件，
“弱信号”“漂移”快捷设置默认开启波动。

基于固定种子的连续插值随机轨迹，在信号时间轴上叠加快/慢频偏游移、时钟速率漂移、噪声底起伏、
相关信号衰落、干扰幅度/频率变化及稀疏突发事件。动态噪声与干扰突发可在对应基准值为 0 时出现；
关闭波动可禁用这些额外事件。波动不是逐帧随机重抽，也不是每行独立改参数。
控制轨迹按 10 ms 信号时间更新，与 UI 帧率、处理分块和 1×/4×/16× 的播放速度无关。
传输中显示实际噪声强度、瞬时频偏、时钟 ppm 和信号幅度；原始滑块显示基准值。

时钟误差通过积分累积采样时间偏移；FM 频偏连续累积相位，所以变化不会通过重新乘绝对时间
制造不连续的采样跳跃。固定种子可复现轨迹，改种子可得到另一种环境；真实麦克风仍属于不可重放的实时输入。
这是一种可控的时变创意信道模型，不是对特定电台、传播路径或硬件的实测拟合。

Terrestrial 的播放器固定为 4:3，控制区可向下滚动。右侧图内调整 Propagation（天线、地形、天气与多径），下方并排提供编码／发射和接收／重建，Reception 与频谱瀑布图已整合进接收机。先开启对应的老化／失真开关，再增加参数；功放 backoff 越小越容易压缩，VSB 过渡带越窄越容易振铃，AGC 响应时间越大恢复越慢。场频偏差增大且捕获窗减小时会滚屏；将场频偏差归零并增大捕获窗可重新捕获。

设置提供缓存路径和最大体积（默认 20 GiB，0 关闭），在所选目录的 Terrestrial-v1 子目录保存完整转换结果。容量清理采用最近使用顺序，保护当前使用中的条目，释放后按最新容量清理；不删除所选目录内的其他文件。临时转换输出卸载或释放 renderer 后自动删除。原始视频保留。

### 保存 Terrestrial 会话

在 Terrestrial 模式使用“文件 → 保存会话”（⌘S）生成 `.analine` 文件；“会话另存为”（⇧⌘S）创建另一份，“打开会话”（⌘O）恢复已有会话，也可以双击会话文件。
文件保存原始视频引用、PAL／NTSC 制式、全部编码／发射／传播／接收参数、噪声种子、播放位置与静音状态，包含旁路时保留的反射强度。没有视频时也可以保存链路设置。

会话不嵌入视频或 FFmpeg 缓存。打开时先检查磁盘缓存，命中则直接使用；未命中时准备 PAL 和 NTSC 两份视频及音频，进度条显示预处理进度，完成后停在保存位置，按播放继续；接收机瞬态、瀑布图历史不保存。
将视频和会话一起移动时保留两者相对目录即可。找不到视频时会提示重新关联，选择替代视频也可以继续；播放位置超出新视频时长时自动限制到最后一帧。
首版仅支持 Terrestrial，Film／SSTV 模式的保存菜单禁用。
