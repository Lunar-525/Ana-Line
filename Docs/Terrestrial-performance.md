# Terrestrial 性能测量与加速

## 固定时钟与可调缓冲

2026-10-10：播放策略改为固定 1×，默认八帧、设置可调 1～60 帧。Core Audio 消费时钟在欠载时继续前进；迟到 PCM 裁掉，缺口静音。呈现器丢弃过期画面，按绝对帧序号累计 DROP；进度在丢帧时继续前进。后台按最近处理耗时提前选帧，避免持续超预算时每次都处理已经来不及显示的帧。跳过 RF 帧后重建接收机，不叠加暂停跳转用的冻结画面预卷。

以下历史性能数据保留当时的缓冲策略与测量结果，不等同于修改后的重新验收。新测试覆盖单帧缓冲和人为每帧增加 80 ms 延迟时的双制式时钟、有效画面与 DROP 计数。


## 发射功率控件回归

新增发射功率后，原生窗口播放场景额外设置 TX +3 dB，实际覆盖图像 RF 缩放、伴音驱动以及两载波功放的交叉压缩。传播、天气、编码／VSB／接收损伤保留，每种制式稳态测量 30 秒。M3 Max release 的最慢生成帧为 PAL **39.36 ms**、NTSC **21.14 ms**，超预算、跳过帧与新增音频欠载均为零，播放速率保持 1×。最大显示间隔为 50.36 / 45.26 ms，相对音频迟到为 9.21 / 10.64 ms，符合原有阈值。未改变帧预算断言；PAL 的余量仍小。原始记录见 [发射功率验收](Benchmarks/M3Max-transmit-power.json)。

功率专项验证覆盖两种制式、±6 dB 电平与前向／返回表读数、PA BYPASS、与 TX 无关的接收噪声底、+12 dB 下的压缩及共享载波标量对照。大 Float 能量归约的比例以 0.001 dB 容差验证，比 GUI 的 0.1 dB 步长小两个数量级。

## 第一轮：核心信号链路

使用 PAL/NTSC 彩条连续处理 10 帧，排除前两帧的预热，取其余 8 帧的算术平均值。信道设置为默认 C/N、15% 多径、4.3 μs 延迟、30° 多径相位及 20 kHz 调谐偏差。每帧保留 FIR、随机数、载波环和接收机的历史状态。以下单位均为 ms/帧。

| 环节 | PAL 优化前 | PAL 优化后 | NTSC 优化前 | NTSC 优化后 |
| --- | ---: | ---: | ---: | ---: |
| CVBS 编码 | 44.62 | 1.45 | 30.55 | 1.00 |
| VSB 调制 | 3.49 | 1.90 | 2.38 | 1.39 |
| RF 信道、噪声与多径 | 13.70 | 5.52 | 9.12 | 3.18 |
| 调谐与 IF 滤波 | 10.83 | 4.37 | 5.91 | 2.82 |
| 载波估计与 PLL | 31.94 | 14.99 | 21.22 | 9.78 |
| AGC 与同步检测 | 4.49 | 4.13 | 2.91 | 2.74 |
| CVBS 解码 | 40.07 | 4.11 | 28.46 | 2.51 |
| 合计 | **149.15** | **36.47** | **100.53** | **23.41** |

核心处理约提升 4.1 倍和 4.3 倍。数值取决于硬件、线程调度、系统负载和信号内容；另一次独立运行 PAL 约 39 ms、NTSC 约 24 ms。

## 并行边界

- CVBS 编码按有效扫描行并行，行内滤波改用 vDSP。同步、消隐与色同步构造仍保持原有时序。
- CVBS 解码先按行提取亮度、色度与 burst，等待这一阶段全部完成，再并行执行 PAL 延迟线组合及 RGB 重建。后者读取前一阶段的邻行结果，避免边计算边修改邻行。
- VSB 的两路 FIR，以及 IF 的四路 FIR，在同一帧内独立并行。每一路单独持有滤波历史，帧之间保持顺序。
- 噪声保留原随机数序列及跨帧状态，将 Box–Muller 的对数、平方根和三角函数批量交给 vForce。AFC 的相位计算也使用向量运算。
- PLL 逐样本反馈、AGC、同步检测和连续帧接收状态仍按时间顺序处理。第二轮复用 AFC 的输入相位，按 `wrap(arg(z) − oscillatorPhase)` 计算误差；±0.2 rad 限幅和 800 Hz 环路带宽保持原值，再批量计算振荡器 sin/cos 和相干解调。

载波恢复仍是较大的单项成本。当前优化使用 CPU 多核与 SIMD，逐样本反馈没有抽样降频。GPU 可承担独立的批量滤波和扫描行计算；当前 CPU 路径已通过本机 M3 Max 的实时播放验收。

## 实际窗口播放与降速判断修正

用户报告全部模块开启，顶部显示 RF 28–30 ms，但播放变慢。该值仅包含 RF/接收与伴音阶段，并非整帧耗时。旧播放器按 `frameDuration / (meanDSPCost × 1.1)` 设置播放倍率，因此 PAL 超过 36.36 ms、NTSC 超过 30.33 ms 即主动降速，甚至仍在各自 40/33.37 ms 的帧预算内。之前的性能验收没有创建可见窗口。

修正包括：

- 在实际平均生产耗时符合帧预算时保持 1×，持续超预算才平滑降速；测量异步生产墙钟与主线程预览更新耗时，保留顺序 RF、PCM FIFO 与共用音画时钟。
- 中频复数混合使用 vDSP，调谐借用输入/输出缓冲，消除逐样本数组写入的所有权检查。
- 功放抗混叠 FIR 直接计算保留的奇相降采样输出，避免先生成整份 2×滤波结果；参考路径保持完整卷积再降采样，用于数值对照。
- 静态参数面板观察独立 `TVControlState`，播放时间与接收指标不再触发天线/天气控制面板更新。配置仍与播放模型双向同步。
- 顶部同时显示 RF、整帧处理耗时与播放倍率；整帧处理值不含可见窗口合成和跳转预卷。

相同的传播/天气/功放场景，最终 release 连续 240 帧测量：PAL 平均 **32.13 ms**、P95 **33.27 ms**、最大 **34.62 ms**；NTSC 平均 **21.51 ms**、P95 **22.10 ms**、最大 **22.52 ms**。两者超预算 **0 / 240**。

## 最慢帧、生成与显示截止时间

平均处理速度和音频 FIFO 不欠载，都不能证明每帧显示流畅。原先的同一循环先等待 RF 生成，再处理画面显示；即使图像和声音都已缓存，一帧生成尖峰也会阻塞显示。实际窗口的长测还发现生成任务返回 MainActor 时会额外等待窗口刷新，最多约 14 ms；这些等待在只测 `TVRenderer` 时看不到。

现在按三条执行路径运行：后台按顺序生成 RF、接收图像与伴音，直接填充线程安全的音画缓冲；Core Audio 消费 PCM；独立主线程显示任务跟随音频时钟取出应显示的帧。平稳的 1× 生成循环不等待主线程。暂停、跳转、换制式和结束会取消生成与显示任务，并清空本次缓冲。实时改变的信道参数通过短锁快照传递，RF 滤波器、振荡器和 PLL 仍逐帧保留状态。

提前保留八帧音画，启动需要先填充缓冲，参数变化也随这段处理提前量到达输出。降速保护使用最近八次生成耗时中的最大值与剩余 PCM，而非平均值；缓存充足时维持 1×。电离远台源按绝对时间初始化各区间的振荡器并行计算，VHF 最大增益下的 AM/FM、任意分块及串行对照误差不超过 2×10⁻⁶。

帧图像与时间只刷新预览和播放条，接收读数与 RX 频谱按媒体时间的 100 ms 桶更新，工作区布局和静态控件不订阅逐帧状态。顶部新增本次播放的生成峰值。此值包含生成、异步返回与入队，不包含启动转码和播放前预卷；不是平均值，也不是屏幕扫描输出计时。

验收增加每次播放的最大生成耗时、超预算次数、最大显示回调间隔、最大相对音频迟到及跳过帧数。正常播放直接断言最慢生成帧 ≤ PAL 40 ms / NTSC 33.37 ms；显示间隔 ≤ 1.5 帧，迟到 ≤ 0.5 帧，漏帧和音频欠载均为零。显示回调阈值包含 PCM 消费时钟的约 10.7 ms 量化步进与轮询调度，不等同于显示器刷新周期。另一个故障注入测试每 60 帧暂停生成 120 ms，同时保持真实顺序 RF 处理，用于验证生成尖峰不能冻结已缓存画面。

相同传播、天气与功放场景，核心连续测量扩展到每种制式 **1200 帧**：PAL 最大 **35.28 ms**、NTSC 最大 **24.13 ms**，超预算均 **0 / 1200**。这些测量不包含可见窗口；实际窗口和故障注入的逐帧验收结果另存于 `M3Max-realtime.json` 的 `tail_latency` 字段。

播放期间声明 `.userInitiatedAllowingIdleSystemSleep + .latencyCritical` 系统活动，避免应用休眠和延迟调度影响播放；暂停、结束或失败时立即释放。不关闭其他应用，也不改变系统全局节能设置。此前失败的峰值记录保留在原始数据中，没有放宽验收阈值。

## 编码／发射／接收电路老化与固定画幅（2026-10-10）

新增编码器微分增益／相位、burst 漂移、VSB 群延迟／峰化、两载波交叉压缩、音频调制器驱动、AGC 动态、H/V 振荡器与捕获电路，以及可调 Y/C 分离。模型和近似范围见 [Terrestrial 链路说明](Terrestrial.md)。播放器固定为 640 × 480；天线、地形、天气、发射与接收控件使用矩形白色面板、细线与阴影，并保持静态控件不观察逐帧图像。

原生窗口测试同时开启原有传播、雨／雪／雾／湿度、雷电、远台干扰、功放；新增设置为交叉压缩 40%、音频驱动 6 dB、DG 20%、DP 15°、burst 漂移 10°、VSB 群延迟 100 ns／峰化 2 dB、AGC 250 ms／过冲 30%／亮度耦合 20%、H 抖动 0.3 μs／振荡器偏差 30 ppm、V 偏差 0.05 Hz／捕获窗 8 行、comb 失效 30%／色度泄漏 10%。所有开关开启不代表所有旋钮都设为极限。

首轮新增模型的生成峰值为 PAL **56.38 ms**、NTSC **36.35 ms**，未通过严格的每帧生成预算，虽然显示和音频缓冲未断供。移除功放采样索引中的重复除法并借用输入缓冲后，PAL 仍有 **40.07 ms** 的超预算帧。进一步将独立 AFC 相位差／功率统计并行化，AGC 电压与后肩钳位改用 vDSP，保留逐样本载波 PLL；接收机与新模型的标量对照继续通过。VSB 设计的频率响应每个频率 bin 只计算一次，功放 LUT 仅在压缩曲线参数改变时重建。

仅对 RF 阶段提高工作队列优先级时，原生窗口 PAL 峰值 **38.91 ms**，NTSC 仍出现 **33.80 ms** 的超预算帧。最终将整帧同步工作放入私有 `.userInteractive` Dispatch 队列，涵盖 FFmpeg 取帧、输入转换、CVBS 和 RF 处理；renderer actor 的状态依然串行独占，滤波与采样任务在帧内并行。调用前后都检查取消。初次转码仍在独立的准备阶段，不属于这个实时工作队列。
