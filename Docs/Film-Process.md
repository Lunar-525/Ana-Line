# Film Damage：逐步虚拟暗房

Film Damage 每次只显示当前阶段：曝光 → 显影 → 停显 → 定影 → 水洗 → 干燥 → 扫描成像。

设置当前条件，点击「开始」推进模拟时间，可暂停，也可手动增加 1 秒曝光或 30 秒处理。「−30 秒」（曝光阶段为 −1 秒）会暂停处理并截断当前阶段最近的操作记录，恢复目标时刻的条件并重新计算胶片状态；不足 30 秒时回到当前阶段起点，不跨越前一阶段。

处理时可修改条件，新条件只作用于后续时间。「完成 → 下一步」接受当前状态，包括处理不足的状态。「撤销到上一步」恢复前一阶段开始前的操作记录、条件、随机种子及扫描参数，清除后续处理。参考时长只表示模型尺度，不是特定胶片配方。

## 计算模型

- 输入：带 ICC 的 RGB 图像。预览最长边 1400 像素，PNG 导出重新读取缓存原图，保留原图分辨率和方向。
- 曝光：线性光、三波段普朗克光源近似（610/550/460 nm）、通用全色乳剂响应、饱和潜影。默认 5500 K；色温在固定总光能下改变各波段比例。RGB 无法恢复完整场景光谱。
- 乳剂：沿深度离散为表层和深层两个有限体积单元。药液从表层边界进入，通过守恒交换扩散到深层。局部供液率受搅动及固定空间场影响；未求解完整三维流体。
- 显影：显影剂浓度、潜影、温度 Q10 近似及药液相对活性决定还原速率。还原消耗卤化银与显影剂，生成金属银。未定影前银与卤化银守恒。
- 停显：酸进入乳剂，中和显影剂，两者均随中和消耗。残余显影可延续至后续湿处理。
- 定影：定影剂进入乳剂并移除剩余卤化银，产生可扩散残留物。金属银保留。
- 水洗：清水交换与乳剂内扩散降低药液及残留浓度。
- 干燥：温度、湿度和气流决定水膜损失；矿物质及残留随蒸发沉积。灰尘随时间和湿表面附着。沉积量驱动水斑强度，固定空间场决定液滴／灰尘位置；未求解单滴流体动力学。
- 成像：金属银和卤化银决定光学密度，按透射关系呈现负片。扫描使用固定参考特性曲线及独立扫描 EV／反差；可在此阶段选择 LUT。颗粒是由银含量与显影液相对颗粒参数驱动的统计近似。

所有化学反应使用非负的指数更新，扩散采用守恒分裂更新，最大时间步长 5 秒。CPU 探针和 Metal 图像内核采用同一方程、同一整数随机场。观察视图显示潜影、金属银、卤化银、化学残留或水膜，黑色为 0、白色为 1。截面图与数值来自中灰探针，并非整张照片的平均值。

这是通用乳剂的简化反应／扩散模型。药液系数、Q10、速率、扩散和粒度系数为模型估计，尚未针对实际胶片实验标定。未模拟长期保存老化。

## 恢复和导出

操作日志、阶段入口快照、当前条件和随机种子随操作保存到本机偏好设置。原始输入另行缓存至 Application Support/AnaLine/FilmLab/source-image。重新打开应用时恢复该输入和进度，以暂停状态继续。载入另一张图片会新建流程；「新胶片」重置当前流程并要求确认。原有非流程效果数据仍可解码，旧艺术效果 API 保留用于兼容。

预览与导出使用相同操作日志、方程和归一化坐标。分辨率改变时存在离散采样差异；化学模型本身不依赖像素尺寸。扫描色调 LUT 在流程末端应用。

## 交互场景

冲洗场景沿用地面电视传播场景的暗色面板、设备图标、拖动调节和局部参数浮窗。上下拖动光源、温控、药液、搅动、水阀或风机调节对应参数；点击设备精确设置。右侧滑块与场景设备共用同一份条件。槽液表面波动跟随搅动／水流，乳剂内粒子数来自实际计算的局部浓度；光线、水流和风线的相位由模拟时间驱动，暂停后静止，回退时随时间回退。场景是中灰探针与设备示意，不是三维流体求解。
