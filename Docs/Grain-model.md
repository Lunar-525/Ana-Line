## 当前实现

`FilmGrainRenderer.swift` 在 Metal 上生成颗粒覆盖场，替换原来的插值噪声。

1. 短边 1000 像素为尺度参考，Size 指名义颗粒直径。空间划为可复现的单元。
2. 在每个单元采样泊松数量的颗粒中心。目标亮度来自该单元中心的输入亮度。
3. Texture 控制半径分布宽度。使用对数正态分布的三点离散近似，概率为 1/6、2/3、1/6；并非连续对数正态采样。
4. 令目标覆盖率为 u，利用 `lambda = -log(1-u) / E[pi R²]` 标定颗粒中心密度，保留均匀灰场的期望亮度。
5. 三个独立深度切片分别计算圆盘并集，平均覆盖率。重叠形成空间相关的颗粒团块。
6. 以 2× 网格采样，再进行基础像素孔径与用户 Blur 对应的高斯滤波，下采样至预览尺寸。
7. 用扫描覆盖率重建亮度。暗化采用与黑色混合，亮化采用与白色混合，避免逐通道硬裁切；Amount 混合输入和重建结果。保留原 alpha。

泊松逆 CDF 上限为 128；当前最大 lambda 约 50。接近纯黑/白的目标直接保留端点，避免无界密度。最大半径小于一个空间单元，查询相邻 3×3 单元覆盖所有可能圆盘。
随机数使用完整 UInt32 seed 和整数哈希，固定参数与同设备结果可复现。

## 参数与限制

- Amount 是创意混合强度，不是 ISO、显影时间或化学浓度。
- Size 是输出归一化尺度，尚未标定底片毫米尺寸、放大倍率或实际胶片颗粒测量。
- Texture 控制粒径多样性，取代旧版“噪声对比度/低频簇”含义。
- Blur 是颗粒覆盖场的扫描平滑，不是显影剂扩散反应方程；基础孔径滤波即使 Blur=0 也保留。
- 当前为显示 RGB 中的单色颗粒重建。三深度切片不是彩色胶片的光谱乳剂层；未模拟染料云、潜影阈值、显影剂耗竭、邻接效应或 H&D 曲线。
- 二倍网格与 Gaussian 是交互质量近似，极小颗粒可能欠采样；没有声称论文级分辨率无关渲染。
- 输入亮度仅在单元中心读取，强边缘附近可能有轻微空间混合。
