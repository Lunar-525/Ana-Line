# Film-Luts feasibility sample

Source: https://github.com/YahiaAngelo/Film-Luts (main, retrieved 2026-10-09).
Six CUBE files are unchanged from upstream. Original README and LICENSE are included.

- negative_new/kodak_portra_400_+.cube
- negative_new/kodak_tri-x_400_+.cube
- colorslide/fuji_provia_100f.cube
- colorslide/kodak_kodachrome_64.cube
- colorslide/fuji_velvia_50.cube
- negative_color/fuji_superia_200.cube

Upstream marks its repository MIT but disclaims ownership of the LUTs.
These files are included for local feasibility evaluation; original asset rights
and input/output color-space provenance remain unverified. sRGB is an explicit
assumption of this preview, not metadata asserted by the LUT authors.
