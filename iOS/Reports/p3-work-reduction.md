# P3：工作量削减（第一轮：一个设计完整但被测量否决的优化）

日期：2026-10-12。设备：iPhone 14 Pro（A16）。背景：三段流水线之后平均并行度已达 **2.98 核**，A16 为 2P+4E（E 核吞吐约为 P 核 1/3，有效容量 ≈ 3.3 个 P 核），**有效算力已用掉约 90%**，因此继续提速只能削减工作量。

## 1. 目标：伴音 46 倍上采样（剖析第一热点，11.1% CPU）

组合器要把 384 kHz 的伴音 IQ 上采样到信道率 17.734475 MHz：

```
709,379 输出 × 51 抽头 × I/Q ≈ 72M 次乘加/帧
```

方案：**两级级联**。

| 级 | 变换 | 抽头 | 输出数/帧 | 说明 |
| --- | --- | ---: | ---: | --- |
| A | 384 kHz → 1.536 MHz（4×） | 51（**与参考完全相同的内核参数**） | 61,440 | 384 kHz 镜像由这一级抑制，与参考一致 |
| B | 1.536 MHz → 17.73 MHz（11.5×） | 13 | 709,379 | 镜像远在 1.3 MHz 之外，短内核足够 |

总乘加从 72M 降到约 25M（2.9×）。

### 质量验证（这是滤波器设计变更，必须证明等价）

| 指标 | 结果 |
| --- | --- |
| 过带下垂 @50 / 150 / 180 kHz | **−0.0074 / −0.0072 / +0.0013 dB**（< 0.08% 幅度） |
| 伴音栅格镜像（204 kHz） | 不高于参考 |
| 与参考的逐样本差 | 修掉延迟后远小于信号 RMS |

过程中发现并修掉一个真实缺陷：**级联会多出一段延迟**（B 级再加 `radius/inputRate` = 2.6 µs），在 150 kHz 上是 2.4 rad 相移，样本差达到 1.4–3.0× RMS。补偿方式是把 B 级的输出索引整体前移 `radiusB × channelRate/intermediateRate ≈ 46` 个信道样本（残差 0.2 样本 ≈ 11 ns）。

## 2. 实测：只省 2%，因此撤销

| 设计 | 每帧耗时 | 节省 |
| --- | ---: | ---: |
| 单级（51 抽头） | 1.40 ms | — |
| 两级级联 | 1.37 ms | **0.03 ms（2%）** |

乘加数少了 2.9 倍却几乎不变快。用一个抽头半径扫描直接定位了原因：

| 抽头半径 | 抽头数 | 每帧耗时 |
| ---: | ---: | ---: |
| 1 | 3 | 0.66 ms |
| 4 | 9 | 0.58 ms |
| 25 | 51 | 1.33 ms |

**把抽头从 51 降到 3 也只快一半** → 约 **0.6 ms 是每个输出的固定开销**（Double 位置/相位链 + 边界判断 + 写出），只有约 0.7 ms 是抽头运算。

而信道率的输出数（709k/帧）是**模型规定、不能改**的，所以：

> **结论：伴音上采样的成本里约一半与抽头数无关，两级化只能动另一半；这条路在保持模型的前提下无法有效优化。**

于是**撤销**该改动（不为 2%、且落在噪声里的收益增加一个新文件与一条失败面），只保留本轮另一项改动：重采样抽头和的 SIMD4 化（lane 分配与折叠顺序不变，**逐位一致**，不亏）。

## 3. 本轮同时纠正的两个自己的误判

1. **视觉载波不是瓶颈**：`carrier()` 本来就是 4 相位精确查表（4fsc 约定 fs/4），并不存在逐样本 `sin/cos`。剖析里的 `VVSINCOSF`/`VVLOGF` 来自伴音 FM 合成与噪声。
2. **`encode` 的逐样本 Double 位置映射不是瓶颈**：改成按 (宽度,行长) 缓存后**零变化**（编译器已做等价优化），零收益又添状态，已撤销。

## 4. 指纹测试的定位调整

`TVSignalFingerprintTests` 现在固定在 **`.full` 参考档位**上做逐位断言——本轮所有优化都保证参考档位逐位不变，所以这道网继续以最严格的方式守着。mobile 档位允许在"已被测量证明不可感知"的地方偏离，这类偏离由各自的容差测试覆盖（例如本轮级联的过带/镜像测试）。

## 5. 战略结论

PAL 损伤在持续热透下仍是唯一不达标的场景（49 ms / 40 ms）。两个事实必须并列看：

- **爆发（冷机）下它是 21.4 ms**，预算 40 ms，余量 47%；
- 持续热透下 49 ms，相差 **2.3 倍**。

也就是说这 2.3 倍几乎全是**降频**，不是工作量。而工作量已经过了一轮剖析验证：热点分散在长尾（CVBS 编解码 ~12%、功放 3.4%、信道 3%、伴音 NCO 1.9%、校验 1.5%），且两个最大单项（上采样、逐样本索引）都已被证明"在保持模型的前提下不可显著优化"。

**因此下一步真正的杠杆是热管理（P4），而不是继续抠工作量。** 若要继续抠，只剩约 10% 量级的零散收益，需要同时改十几处并对每处单独做容差验证。
