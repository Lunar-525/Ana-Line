# iPhone 14 Pro 性能优化暂停记录

已按用户要求停止真机测试，不再继续优化或复测。前三个持续测试场景各运行约 180 秒，最后的损伤 NTSC 保存到约 175.8 秒，整个报告 completed=false。

## 进行过的尝试

| 尝试 | 结果 | 当前状态 |
| --- | --- | --- |
| 视频解码复用像素插值坐标，逐行借用缓冲区，避免逐像素重复计算和边界检查 | 短测 PAL 解码由约 11 ms 降至约 3.6 ms；保留原标量路径作数值对照 | 已保留 |
| 调谐复数旋转按输出区间并行；每段按起始相位初始化 | 数值及跨帧频偏变化检查通过；短测损伤 PAL 的调谐/IF 从约 9.3 ms 降至约 5.9 ms，但该段还包含其他工作，温度/频率不同也会影响时长 | 已保留 |
| Accelerate vDSP_deq22 替代伴音陷波的逐样本递推 | 基础检查通过，但失锁重捕获的两帧像素误差超出原 5e-5 容差；未放宽门槛 | 已撤回 |
| I/Q 重采样合并成 SIMD2<Double> | 逐样本位模式一致、相关回归通过；真机总耗时没有明确收益 | 已撤回 |
| 细分阶段计时、诊断启动模式 | 定位了 PLL、解码、合成与调谐的成本；新增阶段 JSON | 已保留 |
| 同一版本旧/新路径 A/B 开关 | 已构建，正常路径验证通过；尚未安装该诊断版本或执行旧/新对照 | 已准备，未执行 |

## 持续测试已有结果

| 场景 | 原持续平均 ms | 优化后平均 ms | 优化后 P95 ms | 优化后峰值 ms | 优化后超预算 |
| --- | ---: | ---: | ---: | ---: | ---: |
| PAL-D/K / default | 59.46 | 51.20 | 57.00 | 60.06 | 3212/3393 |
| PAL-D/K / damaged | 76.78 | 74.33 | 81.05 | 88.50 | 2223/2223 |
| NTSC-M / default | 42.46 | 46.73 | 51.68 | 65.46 | 3343/3343 |
| NTSC-M / damaged | 62.88 | 61.34 | 71.64 | 228.60 | 2322/2322 |

前三个优化后场景完整，第四个被用户停止。所有已记录帧锁定、RGB/PCM 有限值及伴音样本数检查通过。整帧持续实时目标没有实现。PAL 两场景平均值更低，默认 NTSC 更慢；不能把这些跨时段结果当作精确的因果加速比例。两轮的系统热状态均为 serious（2），但该指标不能保证相同温度、CPU 频率和功耗。优化后报告增加了分段字段，记录/写入开销也与最初长测不完全相同。尚未完成同版本 A/B 验证。

第一轮短测整帧：PAL 默认约 39 ms，PAL 损伤约 49 ms，NTSC 默认约 29 ms，NTSC 损伤约 36 ms。此结果没有持续到长测，不能承诺长期实时。原始短测同样全部记录了 serious 热状态。

验证：最终算法版本的 40 项相关 Release 回归通过，涵盖调谐、编解码、失锁重捕获、伴音、功率与信道；新增诊断开关后另跑的 5 项相关检查通过（与前述测试重叠）。iOS Release 构建通过。采样率、滤波抽头和信号模型没有降低。现有用户的其他未提交改动保留。

手机已重新打开到空闲界面，停止处理。手机当前安装的是保留调谐/解码优化的版本；后备 A/B 版本已构建但未安装。
